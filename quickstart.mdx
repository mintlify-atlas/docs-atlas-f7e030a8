---
title: "Get Started with APScheduler"
description: "Install APScheduler and run your first scheduled task using the sync or async scheduler with interval and cron triggers in under five minutes."
---

This guide walks you through installing APScheduler and running a working scheduler with a scheduled task. By the end you will have a task firing on a fixed interval and understand how to switch to the async API and add a cron-based schedule.

<Steps>

<Step title="Install APScheduler">

Install the package from PyPI using pip:

```bash
pip install apscheduler
```

The base package includes the in-memory data store and local event broker, which are enough for single-process use. To connect to an external database or message broker, install the relevant extra at the same time:

```bash
# SQLAlchemy data store (PostgreSQL, MySQL, SQLite)
pip install "apscheduler[sqlalchemy]"

# MongoDB data store
pip install "apscheduler[mongodb]"

# Redis event broker
pip install "apscheduler[redis]"

# MQTT event broker
pip install "apscheduler[mqtt]"

# AsyncPG event broker (PostgreSQL)
pip install "apscheduler[asyncpg]"

# CBOR serializer (safer alternative to pickle for persistent stores)
pip install "apscheduler[cbor]"

# Multiple extras at once
pip install "apscheduler[sqlalchemy,redis]"
```

APScheduler requires Python 3.10 or later.

</Step>

<Step title="Define a task function">

Any Python callable can be used as a task. Define a plain function to start:

```python
from datetime import datetime

def tick():
    print("Hello, the time is", datetime.now())
```

Functions, methods, static methods, class methods, and any object with a `__call__` method all work as tasks.

</Step>

<Step title="Run a sync scheduler with an interval trigger">

Use `Scheduler` as a context manager, add a schedule, then call `run_until_stopped` to block and process jobs:

```python
from datetime import datetime

from apscheduler import Scheduler
from apscheduler.triggers.interval import IntervalTrigger


def tick():
    print("Hello, the time is", datetime.now())


with Scheduler() as scheduler:
    scheduler.add_schedule(tick, IntervalTrigger(seconds=1))
    scheduler.run_until_stopped()
```

`IntervalTrigger(seconds=1)` fires the task once per second. Run the script and you will see a timestamped line printed every second. Press `Ctrl+C` to stop.

<Note>
`run_until_stopped` blocks the calling thread. Use `start_in_background` instead if you need the rest of your program to keep running after the scheduler starts.
</Note>

</Step>

<Step title="Schedule with a cron trigger">

Swap in `CronTrigger` to run the task on a cron-style schedule. This example runs the task at the top of every hour:

```python
from datetime import datetime

from apscheduler import Scheduler
from apscheduler.triggers.cron import CronTrigger


def send_report():
    print("Sending hourly report at", datetime.now())


with Scheduler() as scheduler:
    scheduler.add_schedule(send_report, CronTrigger(minute=0))
    scheduler.run_until_stopped()
```

`CronTrigger` accepts `year`, `month`, `day`, `week`, `day_of_week`, `hour`, `minute`, and `second` parameters. Omitted fields match every value, following standard cron behaviour.

</Step>

<Step title="Run an async scheduler">

If your application uses asyncio (or Trio), use `AsyncScheduler` instead. The API is identical except that methods are awaited and the scheduler is used as an async context manager:

```python
import asyncio
from datetime import datetime

from apscheduler import AsyncScheduler
from apscheduler.triggers.interval import IntervalTrigger


def tick():
    print("Hello, the time is", datetime.now())


async def main():
    async with AsyncScheduler() as scheduler:
        await scheduler.add_schedule(tick, IntervalTrigger(seconds=1))
        await scheduler.run_until_stopped()


asyncio.run(main())
```

<Tip>
Prefer `AsyncScheduler` in any asyncio or Trio application. The synchronous `Scheduler` wrapper runs an asyncio event loop in a background thread, so using `AsyncScheduler` directly avoids that overhead.
</Tip>

</Step>

<Step title="Run the scheduler in the background">

If you want the scheduler to process jobs while your program does other work, call `start_in_background` instead of `run_until_stopped`:

<Tabs>
  <Tab title="Synchronous">
    ```python
    from apscheduler import Scheduler
    from apscheduler.triggers.interval import IntervalTrigger


    def tick():
        print("tick")


    with Scheduler() as scheduler:
        scheduler.add_schedule(tick, IntervalTrigger(seconds=5))
        scheduler.start_in_background()
        # Your other application code runs here
        input("Press Enter to exit\n")
    ```
  </Tab>
  <Tab title="Asynchronous">
    ```python
    import asyncio

    from apscheduler import AsyncScheduler
    from apscheduler.triggers.interval import IntervalTrigger


    def tick():
        print("tick")


    async def main():
        async with AsyncScheduler() as scheduler:
            await scheduler.add_schedule(tick, IntervalTrigger(seconds=5))
            await scheduler.start_in_background()
            # Your other async application code runs here
            await asyncio.sleep(30)


    asyncio.run(main())
    ```
  </Tab>
</Tabs>

<Warning>
If you start the scheduler in the background and let the script reach its end, the scheduler shuts down automatically. Keep your main program alive for as long as you need the scheduler to run.
</Warning>

</Step>

</Steps>
