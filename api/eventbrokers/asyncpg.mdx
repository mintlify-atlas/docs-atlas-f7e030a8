---
title: "AsyncpgEventBroker — PostgreSQL Event Broker Reference"
description: "API reference for AsyncpgEventBroker, APScheduler's PostgreSQL-native event broker that uses LISTEN/NOTIFY for real-time event delivery across processes."
---

`AsyncpgEventBroker` broadcasts scheduler events across processes using PostgreSQL's `LISTEN`/`NOTIFY` mechanism. Each broker instance opens a dedicated asyncpg connection, registers a listener on a configurable channel, and delivers incoming notifications to local subscribers without polling. This makes it a low-latency, zero-dependency alternative to Redis or MQTT when your data store is already PostgreSQL.

The broker requires the `asyncpg` library and connects via a standard libpq DSN string. A `from_async_sqla_engine()` class method is also provided for convenient integration with an existing SQLAlchemy engine.

<Note>
  PostgreSQL's `NOTIFY` payload is limited to 8000 bytes. The broker enforces a 7999-byte
  limit on serialized events and raises `SerializationError` if an event exceeds this.
</Note>

## Installation

```bash
pip install apscheduler[asyncpg]
```

## Constructor parameters

<ParamField path="dsn" type="str" required>
  A libpq-compatible PostgreSQL connection string, for example:

  ```
  postgresql://user:password@localhost:5432/mydb
  ```

  This is passed directly to `asyncpg.connect()`.
</ParamField>

<ParamField path="options" type="Mapping[str, Any]" default="{}">
  Extra keyword arguments forwarded to `asyncpg.connect()` on each connection attempt.
  Use this to pass SSL contexts, timeouts, or server settings.
</ParamField>

<ParamField path="channel" type="str" default='"apscheduler"'>
  The PostgreSQL `NOTIFY` channel name. All scheduler instances sharing the same
  PostgreSQL database must use the same channel name.
</ParamField>

<ParamField path="max_idle_time" type="float" default="10">
  Maximum number of seconds the listener connection may be idle before a keepalive
  `SELECT 1` query is sent to prevent the server from closing the connection.
</ParamField>

<ParamField path="serializer" type="Serializer" default="JSONSerializer()">
  The serializer used to encode events before publishing and decode them after receiving.
  Defaults to `JSONSerializer`. All scheduler instances sharing a channel must use the
  same serializer.
</ParamField>

<ParamField path="retry_settings" type="RetrySettings" default="RetrySettings()">
  Tenacity-based retry configuration controlling how the broker retries after an `OSError`
  or `asyncpg.InterfaceError`. Defaults to exponential back-off (0.5 s – 20 s) with a
  60-second total stop deadline.
</ParamField>

## Class methods

### `from_async_sqla_engine(engine, options=None, **kwargs)`

Create an `AsyncpgEventBroker` from an existing SQLAlchemy `AsyncEngine` that uses the asyncpg driver. The engine is only used to extract the DSN — it is not held by the broker.

```python
from sqlalchemy.ext.asyncio import create_async_engine
from apscheduler.eventbrokers.asyncpg import AsyncpgEventBroker

engine = create_async_engine("postgresql+asyncpg://user:password@localhost/mydb")
broker = AsyncpgEventBroker.from_async_sqla_engine(engine)
```

The engine's driver must be `"asyncpg"`; a `ValueError` is raised otherwise.

## Usage example

```python
import asyncio
from apscheduler import AsyncScheduler
from apscheduler.datastores.sqlalchemy import SQLAlchemyDataStore
from apscheduler.eventbrokers.asyncpg import AsyncpgEventBroker
from apscheduler.triggers.interval import IntervalTrigger


def my_task():
    print("Running task")


async def main():
    data_store = SQLAlchemyDataStore(
        "postgresql+asyncpg://user:password@localhost/mydb"
    )
    event_broker = AsyncpgEventBroker(
        "postgresql://user:password@localhost:5432/mydb",
        channel="myapp_scheduler",
    )

    async with AsyncScheduler(
        data_store=data_store,
        event_broker=event_broker,
    ) as scheduler:
        await scheduler.add_schedule(my_task, IntervalTrigger(seconds=30))
        await scheduler.run_until_stopped()


asyncio.run(main())
```

### Using `from_async_sqla_engine`

```python
from sqlalchemy.ext.asyncio import create_async_engine
from apscheduler.datastores.sqlalchemy import SQLAlchemyDataStore
from apscheduler.eventbrokers.asyncpg import AsyncpgEventBroker

engine = create_async_engine("postgresql+asyncpg://user:password@localhost/mydb")

data_store = SQLAlchemyDataStore(engine)
event_broker = AsyncpgEventBroker.from_async_sqla_engine(engine)
```

## `PsycopgEventBroker` — psycopg alternative

If you prefer the psycopg driver over asyncpg, APScheduler provides `PsycopgEventBroker` in `apscheduler.eventbrokers.psycopg`. It implements the same `LISTEN`/`NOTIFY` approach using `psycopg.AsyncConnection` and accepts a `conninfo` string in place of a DSN.

```bash
pip install psycopg
```

```python
from apscheduler.eventbrokers.psycopg import PsycopgEventBroker

broker = PsycopgEventBroker(
    "postgresql://user:password@localhost:5432/mydb",
    channel="myapp_scheduler",
)
```

`PsycopgEventBroker` accepts the same `channel`, `max_idle_time`, `serializer`, and `retry_settings` parameters as `AsyncpgEventBroker`, and likewise provides a `from_async_sqla_engine()` class method (requiring a psycopg-dialect engine).
