APScheduler is an in-process task scheduler and job queue for Python. It lets you schedule Python callables to run at specific times, on fixed intervals, or using cron-like expressions — with full support for persistent storage, distributed deployments, and both synchronous and asynchronous workflows.

## Why APScheduler?

APScheduler scales from simple single-process scripts to large distributed deployments with multiple workers sharing a common data store.

## Get started

<Steps>
  <Step title="Install APScheduler">
    ```bash
    pip install apscheduler
    ```
    Install optional extras for persistent storage or distributed brokers as needed.
  </Step>
  <Step title="Define a task function">
    ```python
    def send_report():
        print("Sending daily report...")
    ```
    Any Python callable — function, method, or class with `__call__` — can be a task.
  </Step>
  <Step title="Create a scheduler and add a schedule">
    ```python
    from apscheduler import Scheduler
    from apscheduler.triggers.cron import CronTrigger

    with Scheduler() as scheduler:
        scheduler.add_schedule(send_report, CronTrigger(hour=9))
        scheduler.run_until_stopped()
    ```
  </Step>
</Steps>
